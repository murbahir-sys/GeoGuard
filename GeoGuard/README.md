# GeoGuard — техническое описание

Описание для пользователей — в [README в корне репозитория](../README.md).

Приложения из списка настроек разрешены **только в одной выбранной стране** (определяется по внешнему IP).
В любой другой стране — и пока страна не подтверждена — они немедленно закрываются, а с правами администратора
ещё и лишаются доступа к сети вне VPN-адаптера (файрвол).

Автор: Савицкий Святослав. Справка доступна в самой программе (значок в трее → «Справка», клавиша F1 в настройках).
Флаги стран: [flagpedia.net](https://flagpedia.net) (PNG шириной 320 px с flagcdn.com, лежат в `Assets/Flags` и встроены в программу; настоящие пропорции).

## Установка

Запустите `GeoGuard-Setup-<версия>.exe` (запросит права администратора). Установщик:

* ставит программу в `C:\Program Files\GeoGuard` вместе с .NET — ничего предустанавливать не нужно;
* по желанию включает запуск вместе с Windows (задача планировщика с наивысшими правами) и значок на рабочем столе;
* при обновлении поверх старой версии закрывает работающую копию; правила файрвола при этом сохраняются;
* при удалении («Приложения и возможности») снимает правила файрвола и автозапуск и спрашивает, удалять ли настройки.

Установщик не подписан цифровой подписью, поэтому Windows может показать «Неизвестный издатель» — это нормально.

## Как ведёт себя защита при запуске

При запуске GeoGuard сначала определяет страну, а уже потом действует по настройкам: пока первого ответа нет, приложения из списка
не закрываются (в шапке «Определяем страну…»). Первый ответ решает: совпала разрешённая страна — всё работает, не совпала — приложения закрываются.
Если страну не удалось получить два раза подряд (или ответа нет 30 секунд), приложения закрываются. После этого действуют строгие правила:
любая смена сети сразу сбрасывает подтверждение, а возврат разрешения требует двух совпавших проверок подряд.

## Запуск и права

* Обычный запуск запрашивает права администратора (UAC): они нужны для правил файрвола и автозапуска через планировщик.
  Если отказать — программа работает в ограниченном режиме: приложения закрываются, файрвол не используется.
* Настройки: `%AppData%\GeoGuard\settings.json`; окно настроек — двойной щелчок по значку в трее.
* В окне настроек: «Применить» сохраняет и применяет изменения, не закрывая окно (активна, только если что-то изменено);
  «Сохранить» делает то же и закрывает окно; «Отмена» закрывает без сохранения.

### Ключи командной строки

| Ключ | Действие |
|---|---|
| `--no-elevate` | не запрашивать права администратора (файрвол недоступен) |
| `--remove-rules` | удалить правила файрвола и автозапуск |
| `--selftest-firewall` | проверить файрвол на этом компьютере (тестовое правило, рабочие не затрагиваются) |
| `--enable-autostart` / `--disable-autostart` | включить / выключить автозапуск (использует установщик) |
| `--silent` | служебные команды без окон сообщений |

## Когда приложения закрываются при смене сети

GeoGuard реагирует на смену сети, только когда мог измениться внешний IP. Следит он за:

* **VPN-адаптером**, выбранным на вкладке «Сеть» (любой VPN, создающий адаптер; можно задать часть имени или описания,
  несколько — через «;»; по умолчанию не выбран): включился, выключился, сменил адрес;
* **адаптерами со шлюзом** (реальный выход в интернет: кабель, Wi-Fi, точка доступа, мост Hyper-V).

Запуск и остановка WSL, Docker, виртуальных машин и Hyper-V Default Switch **ничего не закрывают**: у их адаптеров нет шлюза.
Если шаблон VPN в настройках пуст, следим только за адаптерами со шлюзом — так GeoGuard работает и без VPN.

## Что делает файрвол

Для каждого приложения из списка, у которого известен путь к `.exe`, создаётся одно **блокирующее исходящее** правило
`GeoGuard: <имя>.exe [...]`:

| Состояние | Правило |
|---|---|
| страна подтверждена и совпадает | закрыты все интернет-интерфейсы, **кроме VPN-адаптера** |
| страна чужая / не подтверждена | закрыты **все** интерфейсы |

«Интернет-интерфейс» — адаптер со шлюзом, Wi-Fi или сейчас не работающий адаптер (мог бы включиться).
Внутренние сети WSL, Docker, VMware, Hyper-V Default Switch шлюза не имеют и правилом не закрываются.

Правила не затрагивают сам VPN и другие программы. При падении VPN приложение не получает выход через обычную сеть
даже до того, как GeoGuard успеет отреагировать.

Процессы и папки известных VPN-клиентов (список в `VpnClients.cs`: AmneziaVPN, WireGuard, OpenVPN, Proton VPN, NordVPN,
Mullvad и др.) защищены: GeoGuard не закрывает их и не создаёт для них правил, даже если их внести в список.
Пока VPN-адаптер не выбран, в шапке окна настроек показывается предупреждение, а файрвол не работает.

## Выход, сбой и удаление

* **«Выход» в меню трея** отключает защиту и удаляет правила файрвола.
* При выключении компьютера или сбое правила **остаются** и продолжают защищать до следующего запуска GeoGuard.
* Если GeoGuard удалён или нужно снять все правила вручную:
  * `GeoGuard.exe --remove-rules` — удаляет правила файрвола и автозапуск;
  * или в PowerShell от администратора: `Get-NetFirewallRule -DisplayName "GeoGuard*" | Remove-NetFirewallRule`
    и `schtasks /Delete /TN GeoGuard /F`.

## Сборка из исходников

Нужны .NET SDK 10 и Inno Setup 6 (`winget install JRSoftware.InnoSetup`).

```
powershell -ExecutionPolicy Bypass -File build\build.ps1 -RunTests
```

Скрипт прогоняет тесты, публикует самодостаточную сборку в `dist\app` и собирает установщик
`dist\installer\GeoGuard-Setup-<версия>.exe` (версия берётся из `GeoGuard\GeoGuard.csproj`).

* Иконка и картинки установщика генерируются `tools\MakeAssets.ps1` (результат лежит в `GeoGuard\Assets` и `installer`).
* Пробный установщик без прав администратора, файрвола и планировщика: `ISCC.exe /DTESTMODE installer\GeoGuard.iss`.
* Снимки окон для визуальной проверки: `GeoGuard.Tests.exe <жертва> --render-ui <папка>`.

## Тесты

```
dotnet build GeoGuard.Tests
GeoGuard.Tests\bin\Debug\net10.0-windows\GeoGuard.Tests.exe GeoGuard.TestVictim\bin\Debug\net10.0\geoguard_testproc.exe
```

Тесты используют подставные геолокацию, сеть и файрвол, а «жертвой» служит собственный процесс `geoguard_testproc`.
Настоящий VPN они не затрагивают.

Живая проверка сервисов геолокации (нужен интернет, в обычный набор не входит): `GeoGuard.Tests.exe <жертва> --geo-live`.

## Сервисы геолокации

Список — в `GeoLocationService.DefaultProviders`; используются только сервисы, разрешающие бесплатное использование,
в том числе коммерческое, без ключа: ipwho.is, api.country.is, get.geojs.io.

* У ipwho.is в бесплатном режиме 1000 запросов в сутки, поэтому к нему обращаемся не чаще раза в 2 минуты
  (не больше 720 запросов в сутки при круглосуточной работе). Пропущенный сервис не участвует в проверке — решают остальные.
* Сервис, ответивший 429, не опрашивается 15 минут или столько, сколько указано в Retry-After (но не больше часа).
* Если остальные сервисы недоступны, сервис с интервалом опрашивается без ожидания.
